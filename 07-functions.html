Functions

Functions are reusable blocks of code that perform a specific task. They can take input in the form of parameters and can return a value. Functions help to organize code and make it more readable and maintainable.

In JavaScript, you can define a function using the function keyword, followed by the function name, parentheses for parameters, and curly braces for the function body. Here is an example:

      
        function greet(name) {
          return `Hello, ${name}!`;
        }
