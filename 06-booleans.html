Booleans

Booleans are a data type that can only have two values: true or false. They are often used in conditional statements to control the flow of a program.

In JavaScript, you can create a boolean value by using the keywords true or false. For example:

      
        let isRaining = true;
        let isSunny = false;
        Alert(5>3);

Comparison Operators

Comparison operators are used to compare values and return a boolean result. Here are some common comparison operators in JavaScript:

  • === - Strict equality
  • !== - Strict inequality
  • > - Greater than
  • < - Less than
  • >= - Greater than or equal to
  • <= - Less than or equal to

Logical Operators

Logical operators are used to combine boolean values and return a boolean result. Here are some common logical operators in JavaScript:

  • && - AND
  • || - OR
  • ! - NOT

Truthy and Falsy Values

In JavaScript, some values are considered "truthy" and some are considered "falsy". A truthy value is a value that is considered true when evaluated in a boolean context, while a falsy value is a value that is considered false. Here are some examples of truthy and falsy values:

  • Truthy values: non-empty strings, non-zero numbers, objects, arrays, true
  • Falsy values: empty strings, 0, null, undefined, false

    • Conditional Statements

    Conditional statements are used to execute different code based on certain conditions. The most common conditional statement in JavaScript is the if statement. Here is an example:

             

        
          let age = 18;
          if (age >= 18) {
            console.log("You are an adult.");
          } else {
            console.log("You are a minor.");
          }
